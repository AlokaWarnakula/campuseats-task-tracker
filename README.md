# CampusEats Task Tracker

A small repository for SE3090 Lab 08. It is used to practise the team workflow:
branch -> commit -> pull request -> review -> merge, with GitHub Issues for
planning and GitHub Actions for automatic checks.

## Folder structure

campuseats-task-tracker/
  README.md
  .gitignore
  src/tasks.js
  .github/workflows/ci.yml

## How to run

node src/tasks.js
